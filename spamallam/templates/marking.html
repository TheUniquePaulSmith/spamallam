SPAM marking

When a delivered message's AI verdict matches one of the triggers below, SpamAllam inserts a warning banner at the top of the body (converting plaintext to HTML so it renders), and can break remote images so tracking pixels never fire. This never touches S/MIME- or PGP-signed messages, and any rewrite failure silently falls back to delivering the message untouched.

Break remote images / tracking pixels

Rewrites remote (http/https) <img src> and legacy background= attributes to an inert placeholder. Embedded (cid:/data:) images are never touched.

Classification footer

HTML for the classification footer, inserted right before </body> (or appended if no </body> tag) when a label applies and placement is set to "footer" or "both". Token: {tags} — the space-separated MailPlus-keyword tags for the labels the AI assigned.
