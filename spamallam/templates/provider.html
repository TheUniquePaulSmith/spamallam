mTLS client certificate (custom provider, optional)

Present a client certificate when connecting to the custom provider. The PFX file and its password are stored encrypted at rest; the decrypted key exists only in memory during provider calls and is never shown again.

Still presents the client certificate above for mTLS auth — this only stops verifying the server's TLS chain. Use this only when the endpoint (or a proxy in front of it) has a self-signed/internal-CA certificate and something in that path already authenticates the client certificate itself. Without this, a self-signed server cert fails with "unable to get local issuer certificate".
