Failure mode

What happens to a message when the AI provider is unreachable, times out, or errors.

Drop threshold

Messages classified PHISHING or MALICIOUS at or above this confidence are silently discarded (never bounced). Below it they are delivered tagged.

Analysis timeout

Maximum time for one message's full analysis — including every tool-calling round trip — before it's treated as a failure and handled per the failure mode above. A self-hosted/local model with a multi-tool investigation can need more than the default; raise this if you see TimeoutError in Logs after tool calls completed. Leave blank to use this deployment's AI_TIMEOUT_SECONDS environment default (currently {{ env_timeout_seconds }}s) — that one needs a container restart to change, this field takes effect on the next message.
