Mail classification

When enabled, the AI may tag each message with 0–3 of the labels below (as part of its normal analysis — no extra LLM call). The result is emitted as the X-SpamAllam-Labels header (for scripting/log tooling) and/or a small footer in the body. The footer's HTML template is customizable on the Marking page, alongside the SPAM warning banner.

Synology MailPlus's filter-rule builder cannot match on headers — only From/To/Subject/Keyword/Size. So to apply a native MailPlus "Label" automatically, keep the body footer on (default) and create a MailPlus filter rule per label with a Keyword condition matching that label's exact tag shown below, e.g. action "Add label: Newsletter".
