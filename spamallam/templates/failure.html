Failure policy

What happens to a message when a security control cannot run — the LLM provider is unreachable, rspamd is down, ClamAV cannot scan. This is the one screen where a wrong choice quietly turns the gateway into a pass-through, so each option states what an attacker gains from it. Full write-up in docs/FAILURE-POLICY.md.

These matter because an attacker who cannot beat the filters can instead try to exhaust them — expensive messages, floods of concurrent mail, provider throttling. If the answer to “the scanner is unavailable” is always “deliver anyway”, then making a control unavailable is the bypass.

Antivirus failure detection

A failed scan is recognised by these rspamd symbols. ClamAV's is CLAM_VIRUS_FAIL; VirusTotal's is deliberately not listed by default, because a rate-limited hash lookup should not defer your mail.

Known gap: rspamd emits no “scanned clean” symbol, so “scanned, clean” and “the antivirus module was never in the path” look identical from here. This detects scanner errors, not scanner absence.
